# Layout Components

Компоненты для верхнего бара приложения, построенные на композиции через слоты.

## Архитектура

### BaseTopBar.vue
**Базовый компонент-шаблон** со слотами. Предоставляет структуру и адаптивную верстку.

#### Слоты
- `left` - левая секция (логотип, кнопка назад и т.д.)
- `right` - правая секция (кнопки действий)

#### Props
- `containerClass` - дополнительные классы для контейнера

#### Пример
```vue
<BaseTopBar>
  <template #left>
    <!-- Ваш контент слева -->
  </template>
  <template #right>
    <!-- Ваш контент справа -->
  </template>
</BaseTopBar>
```

---

### AppTopBar.vue
**Шапка для основного приложения** с логотипом и кнопкой запроса.

#### События
- `@action` - клик на кнопку "Отправить запрос"

#### Пример
```vue
<AppTopBar @action="handleAction" />
```

---

### ModalTopBar.vue
**Шапка для модальных окон** с кнопкой "Назад" и заголовком.

#### Props
- `title` - заголовок (по умолчанию "3D План квартиры")
- `containerClass` - дополнительные классы для контейнера

#### События
- `@back` - клик на кнопку "← Назад"

#### Пример
```vue
<ModalTopBar 
  title="Мой заголовок"
  @back="handleBack"
/>
```

---

## Преимущества архитектуры

✅ **DRY** - нет дублирования кода  
✅ **Гибкость** - легко создавать новые вариации  
✅ **Композиция** - через слоты вместо пропсов  
✅ **Простота** - каждый компонент делает одну вещь  
✅ **Адаптивность** - автоматически работает на всех устройствах

## Создание новой вариации

Просто используйте `BaseTopBar` и заполните слоты:

```vue
<template>
  <BaseTopBar>
    <template #left>
      <!-- Ваш левый контент -->
    </template>
    <template #right>
      <!-- Ваш правый контент -->
    </template>
  </BaseTopBar>
</template>
```
